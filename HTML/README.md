# Pastelería Mil Sabores

Sitio web estático desarrollado como producto de la primera evaluación de Full Stack 2. El proyecto presenta la tienda ficticia Pastelería Mil Sabores, con catálogo, detalle de productos, carrito, registro e inicio de sesión, perfil, seguimiento de pedidos, boleta, blog, contacto y sección institucional.

## Tecnologías

- HTML
- CSS
- JavaScript

## Cómo abrir

Abre `index.html` en un navegador. Las páginas y recursos se enlazan con rutas relativas dentro de esta carpeta, por lo que también puedes usar un servidor local estático para recorrer el sitio.

## Alcance de la demostración

El proyecto es una interfaz de evaluación y no se conecta a un servidor. Los datos de usuarios, sesión, carrito e historial se guardan en `localStorage` del navegador. Los flujos de registro, compra, pago y seguimiento son demostrativos; no uses contraseñas ni datos personales reales.

## Estructura

- `index.html` y otras páginas HTML: vistas del sitio.
- `css/`: hojas de estilo.
- `js/`: lógica de interfaz y datos de demostración.
- `img/`: imágenes del sitio.
